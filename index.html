📖 系統使用說明

一、基本操作與名詞解釋

  • 新增持股：點擊「+新增」，輸入股票代號（系統內建熱門 ETF 字典會自動帶入名稱）、持有數量及買入均價。
  • 總損益 (ROI)：系統會依據您填寫的「買入均價」與現價自動計算總未實現損益與報酬率(%)。未填寫均價則僅計算今日損益。

二、群組分頁與介面功能

  • 多群組管理：進階設定中最多可開啟 5 個獨立分頁（雙擊標籤可自訂名稱），方便將「存股」、「短線」分開管理。
  • 指數卡片拖拽：首頁上方的國外指數列支援直接以滑鼠或手勢長按拖動排序。
  • 即時新聞：首頁上方跑馬燈會即時抓取財經新聞，可於設定中關閉以節省畫面空間。

三、🔑 Fugle API 雙引擎設定原則

  • 為什麼需要 API Key？本系統為純前端架構，依賴「富果 (Fugle) 開發者 API」直接向您的設備傳送即時股價。請前往 Fugle 官網免費註冊並取得 API Token。
  • 雙 Key 輪替優勢：Fugle 免費版有「每分鐘 60 次」的請求限制。強烈建議申請並填寫兩組不同的 API Key。系統會自動交替使用，突破單一 Key 限制，將更新速度提升至 8 秒/次，並大幅降低斷線率。
  • 全天極速不降速更新：系統採全天候 24 小時不降速即時更新（雙 Key 維持 8 秒/次，單 Key 15 秒/次），無論盤中、盤後試搓、零股或夜間均保持最高頻率輪詢，隨時掌握最新即時報價與資產變動。

四、⚠️ 資料安全與備份

您的所有持股資料、歷史記錄及 API Key 皆 100% 儲存於您目前使用的設備瀏覽器中（Local Storage）。我們沒有伺服器，無法看見您的資料，但也無法幫您復原。

強烈建議：請務必養成習慣，定期點擊進階設定內的「📥 匯出」將資料下載備份！
